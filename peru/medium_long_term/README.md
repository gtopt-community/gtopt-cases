# Peru — medium / long term (COES SDDP base cases)

> [!WARNING]
> Provided **AS IS**, not validated by the publishers, who keep all
> rights over the data.  See the [disclaimer](../../DISCLAIMER.md).

[`coes_mrfo_2026-2029/`](coes_mrfo_2026-2029/README.md): four one-year
hydrothermal SDDP cases (2026, 2027, 2028, 2029; 12 monthly phases, 56
historical hydrologies, DC network with losses) converted with
`sddp2gtopt` from the COES PSR SDDP base cases of the MRFO 2026-2029
study.  The inputs, which differ between years only in `sddp.dat`, are
stored once in `coes_mrfo_2026-2029/source/`.
